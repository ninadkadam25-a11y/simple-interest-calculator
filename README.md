# Simple Interest Calculator

## Project Description

This project is a simple interest calculator implemented using a Bash script.

It calculates simple interest using the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal amount
- Rate of interest
- Time period

## Output

The calculated simple interest is displayed to the user.
